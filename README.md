# 🚀 LinkedIn Content System (Content Operating System)

A lightweight system to manage, generate, and analyze LinkedIn content using a structured pipeline.

---

## 🧠 Why I built this

Most content creation is chaotic:

* ideas get lost
* no tracking of what works
* no feedback loop

This project turns content creation into a **system**.

---

## ⚙️ Features

### 📝 Content Management

* Create and store post ideas
* Track content lifecycle:

  * draft → ready → posted

### 🤖 AI Workflow

* Generate structured prompts for LinkedIn posts
* Store final generated content

### 🖼 Image System

* Generate image prompts for visuals

### 📊 Analytics

* Track:

  * views
  * likes
  * comments
* Compare performance across posts

### 🧠 Strategy Layer

* Identify best-performing topics
* Suggest next content direction

---

## 📊 Dashboard

* Total posts
* Draft / Ready / Posted split
* Topic distribution
* Performance metrics

## 🧱 Tech Stack

* Python
* Streamlit (UI)
* CSV-based database

---

## 🚀 How to run

```bash
pip install -r requirements.txt
python -m streamlit run app.py
```

---

## 📁 Structure

```
app.py → UI layer
post_manager.py → data handling
database.csv → storage
```

---

## 🧠 Key Insight

This is not a content tool.

It’s a **Content Operating System**:

* input → idea
* processing → structuring
* output → post
* feedback → analytics
* iteration → strategy
